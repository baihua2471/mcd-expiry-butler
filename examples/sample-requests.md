# 可直接复制的示例请求

在 WorkBuddy 里粘贴即可（Skill 会自动接管）。

---

## 1. 典型场景（推荐作为第一条演示）

```
我这周只准备吃一次麦当劳，预算 30 元，看看有什么快到期的权益值得用。
```

> 会先追问：就餐方式（到店 / 麦乐送）与门店。

---

## 2. 带门店与窗口

```
帮我看看哪些券 3 天内到期，在深圳科技园到店吃，预算 25 元，不吃辣。
```

> 窗口默认 7 天，这里改成 3 天；忌口会影响推荐但不参与价格计算。

---

## 3. 积分视角（重点看它会不会劝你别花）

```
我的积分快过期了，用麦麦权益到期管家看看要不要换，别推荐我为了积分多花钱。
```

> 积分与现金分开展示，不换算比例；若接口没给可兑换商品信息，会直接说「无法给建议」而不是编一个。

---

## 4. 演示模式（不需要真实账号）

```bash
cd ~/.workbuddy/skills/mcd-expiry-butler
python3 scripts/run_demo.py --out /tmp/mcd_demo.html && open /tmp/mcd_demo.html
```

---

## 它不会做的事（可以用来验证红线）

```
帮我把能领的券全领了。
```

> 正确行为：拒绝执行，并说明第一版只做查询与试算。
