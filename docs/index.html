这是什么

一个真实使用麦当劳官方 MCP 的 WorkBuddy Skill。它只读查询你快到期的优惠券和积分， 按你给的预算给出最多两套用餐方案，金额全部经过官方价格试算——然后明确告诉你， 哪些权益不值得为了到期而硬消费。

  • 预算优先于消耗权益：没有合适方案时，会直接建议你这次别用
  • 金额必须官方试算，不用券面额或估算冒充实付价
  • 缺什么数据就标「未提供」，不猜、不补、不把缺失当 0
  • 第一版只做查询与试算：不领券、不兑换、不下单
