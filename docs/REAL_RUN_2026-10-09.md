## 2. 已验证的结论

1. **到期时间可靠**：`query-store-coupons.tradeDateTime` 精确到秒（如 `2026-10-05 10:30:00-2026-10-09 23:59:59`）。
2. **券的可用性必须按门店判定**：卡包 14 张 → 指定门店 + 到店渠道下仅 **2 张**可用。这正是本 Skill 存在的理由。
3. **价格可追溯**：带 `couponId + couponCode` 的 `calculate-price` 返回真实应付；本次实测 ¥14.00 → **¥9.90**（`discount=410` 分）。
   → 因此「省 4.10 元」有官方基准，不是模型估算。
4. **积分无具体到期日期**：只有「本月 / 下月将过期」数量，没有日期字段。
5. **`query-my-coupons` 不能用于试算**（缺 `couponId`），只能做概览对照。
6. **`query-meal-detail` 不含价格**，价格只能来自 `query-meals`（菜单价）或 `calculate-price`（试算价）。
7. **积分商城存在数据不一致**：部分商品 `downTime` 已过期但 `status=2`（上架）。本 Skill 如实标注冲突，不自行判定哪个正确。

## 3. 仍未验证 / 无法验证

| 项 | 说明 |
|---|---|
| 外送（麦乐送）链路 | 需要真实收货地址（`delivery-query-addresses`），涉及个人隐私，本次未做 |
| 配送费 / 打包费实际取值 | 到店场景返回中无这两个字段；外送场景未验证 |
| 积分兑换下单 | 红线范围内，不做 |
| 多券叠加 | 接口未提供叠加规则，本 Skill 直接**不假设可叠加** |
| 得来速（beType=5）`beCode` 链路 | 未验证 |
