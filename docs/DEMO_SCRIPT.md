# 一分钟演示脚本

目标：让评委在 60 秒内看懂「它解决什么问题」和「它的价格是可信的」。

---

## 版本 A：无需账号（30 秒，最稳）

```bash
cd mcd-expiry-butler
python3 scripts/run_demo.py --out demo_output/demo_report.html
open demo_output/demo_report.html
```

旁白（约 30 秒）：

1. 「卡包里躺着十几张券，多数人不知道哪些快到期、哪些这家店根本用不了。」
2. 「这是演示模式，顶部明确写着**样例数据，非实时账户结果**。」
3. 「中间是权益清单：快到期、已过期、渠道不匹配，各自标了原因。」
4. 「下面是两套方案，金额后面标着**已验证（官方试算）**——这不是券面额，是真跑过价格试算的应付金额。」
5. 「最下面是**不建议使用**：为了凑一张券而多点 20 块，它不推荐。」

## 版本 B：真实账号（60 秒，更有说服力）

在 WorkBuddy 里输入：

> 我这周只准备吃一次麦当劳，预算 30 元，深圳科技园到店吃，看看有什么快到期的权益值得用。

旁白分镜：

| 时间 | 画面 | 说什么 |
|---|---|---|
| 0–10s | 提问 | 「一句话需求，预算、门店、就餐方式都给了。」 |
| 10–25s | 追问与查询 | 「缺信息它会集中问一次，然后查门店、查该店可用券、查积分。」 |
| 25–40s | 试算 | 「每个候选方案都真的调了官方价格试算，不是估算。」 |
| 40–55s | 结果页 | 「两套方案 + 推荐理由 + 不建议用的权益 + 未确认条件，全部有查询时间。」 |
| 55–60s | 收尾 | 「预算优先：没有合适方案时，它会直接说这次别用。」 |
